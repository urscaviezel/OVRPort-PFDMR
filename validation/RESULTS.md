# Release validation — 0.1.0-beta.1

Validated on 2026-10-11. The public application was built from this repository, not by modifying a private application JAR.

- Gradle Windows desktop build: passed, JDK 21, Gradle 8.13.
- Java integration suite: **27/27 passed** against the public beta JAR with JVM verification enabled. Includes registration/defaults, 56 reference OpenXR exports, malformed/unsupported inputs, safe repeated patching, patch ordering, APK rebuild, signature verification, disabling the fix, and exact original-loader restoration.
- Native suite: **18/18 passed** on a Play For Dream MR ARM64 device, using the production wrapper and a mock runtime. Includes parallel orientation math, opposite quaternion signs, preserved eye positions/IPD/FOV, direct/proc-address dispatch, view counts and error forwarding.
- Portable launcher: starts successfully using the bundled Temurin runtime.
- UI smoke test: APK opens, both PFDMR options start disabled, the minimum option clears other patches, and the stereo option can then be enabled independently.
- Distribution ZIP: integrity checked; contains no game APK, OBB or private signing key.

The native suite is a simulated runtime test, not an in-game visual test. The underlying approach was previously reported working in a private Batman: Arkham Shadow test. Compatibility of this public beta with other applications remains unverified.

The build removes obsolete dependency signature files from the merged executable JAR. APK signatures generated by the patcher are tested independently and verified successfully.
